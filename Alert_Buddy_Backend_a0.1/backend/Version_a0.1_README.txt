//Instructions://

1. Generate a medrunner api token (see Medrunner documentation link above)
2. Open a cmd in the backend folder and run 'parent_app.js' with Node.js.
3. Paste your medrunner api token in the '.env' file that was created in the backend folder.
4. Make sure you finished setting up WLED on your ESP32 and connected it to your Wifi network succesfuly.
5. paste your WLED/ESP32 ip address in the 'config.json' file found in '../shared' folder.
6. Run 'parent_app.js' again. If you see 'Listening...' in the command window, you are good to go.
7. You will need to set up some presets in WLED. The default preset for emergencies can be set up in the 'config.json' file found in '../shared' folder.
